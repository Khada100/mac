# 이미지 매크로 (안드로이드판)

윈도우용 `image_finder_gui.py`(BlueStacks 이미지 검색 매크로)를 **안드로이드폰에서 직접** 돌아가게 옮긴 앱입니다.
동작 순서는 윈도우판과 같고, 버튼·옵션 이미지는 **폰에서 바로 캡처해서 등록**합니다.

## 동작 순서 (윈도우판과 동일)

1. 등록한 **회피 옵션 이미지**(감속 효과, 빙결 시간 …)를 화면에서 검색
2. 하나라도 보이면 → **새로고침(reload)** 클릭 → 1번으로
3. 하나도 없으면 → **전투 시작(start)** 클릭 → 40초 대기
4. **확인 1(collect1)** → **확인 2(collect2)** 클릭 → 1번으로

| 윈도우판 | 안드로이드판 |
|---|---|
| mss 화면 캡처 | MediaProjection (화면 캡처 권한) |
| pyautogui.click | 접근성 서비스 제스처 (루팅 불필요) |
| cv2.matchTemplate (그레이스케일, TM_CCOEFF_NORMED, 배율 0.95/1.0/1.05) | 같은 OpenCV, 같은 방식 → 임계값 그대로 사용 가능 |
| `templates/`, `button/` 폴더에 PNG 넣기 | 게임 화면에서 📷 버튼 → 손가락으로 잘라서 저장 (갤러리 스크린샷도 가능) |
| tkinter 창 (시작/정지/로그) | 게임 위에 떠 있는 조작 버튼 + 앱 화면 (설정/로그/이미지 관리) |

### 윈도우판에서 고친 점
- **옵션 임계값 / 버튼 임계값 분리** (옵션 기본 0.92). 윈도우판 기본값 0.85에서는 '기절 시간'이 '빙결 시간'으로 오인식됐습니다 (0.876).
- **확인 버튼 대기 시간 제한** (기본 120초). 전투에서 지는 등의 이유로 확인 버튼이 안 나오면 처음 단계로 돌아갑니다. 0으로 두면 윈도우판처럼 무한 대기합니다.
- 오류가 나도 조용히 멈추지 않고 로그를 남긴 뒤 재시도합니다 (5번 연속이면 정지).
- 정지 후 바로 다시 시작해도 매크로가 두 개 동시에 돌지 않습니다.
- 클릭 좌표 = 캡처 좌표(전체 화면)라서 창 위치에 따라 좌표가 어긋나는 문제가 없습니다.
- 앱 화면이나 이미지 등록 화면이 열리면 매크로를 자동으로 정지합니다. 앱 화면에 보이는 게임 버튼을 잘못 누르지 않게 하기 위해서입니다.

## 1. 빌드 & 설치

### 방법 A — GitHub Actions로 자동 빌드된 APK 받기 (PC에 아무것도 설치 안 해도 됨)

이 저장소에 코드를 올리면 GitHub가 APK를 자동으로 빌드합니다 (`.github/workflows/android.yml`).
빌드된 APK는 매번 **최신 릴리스**에 올라가요.

- **폰에서 바로 받기**: 폰 브라우저로 아래 주소를 열면 APK가 내려받아집니다. 받은 파일을 눌러 설치하세요. '출처를 알 수 없는 앱' 설치를 허용해야 해요.
  `https://github.com/Khada100/mac/releases/download/latest/ImageMacro.apk`
- 또는 저장소의 **Actions** 탭 → 초록색 ✅ 실행 → 맨 아래 **Artifacts**에서 `ImageMacro-debug-apk`(zip)를 받을 수도 있어요.

빌드할 때마다 에뮬레이터(Android 14) 자동 테스트도 함께 돌아갑니다.
테스트 내용: 앱 실행 → 접근성 연결 → 화면 캡처 → 홈 화면 아이콘을 템플릿으로 등록 → 매크로가 그 아이콘을 찾아 실제로 터치하는지 확인.

### 방법 B — Android Studio에서 직접 빌드

1. [Android Studio](https://developer.android.com/studio)를 설치합니다.
2. **File → Open** 에서 이 폴더(`ImageMacro`)를 엽니다. 처음에는 Gradle Sync가 몇 분 걸려요. Gradle, Android SDK, OpenCV를 인터넷에서 받기 때문입니다.
3. 둘 중 한 가지 방법으로 설치합니다.
   - **USB로 바로 설치**: 폰에서 *개발자 옵션 → USB 디버깅*을 켜고 USB로 연결한 뒤 ▶ **Run**을 누릅니다.
   - **APK 파일로 설치**: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**를 누르면 `app/build/outputs/apk/debug/app-debug.apk`가 생깁니다. 이 파일을 폰으로 옮겨 설치합니다.

명령줄로 빌드하려면 이 폴더에서 `gradlew assembleDebug`(윈도우) 또는 `./gradlew assembleDebug`(맥·리눅스)를 실행합니다. 이때 Android SDK 경로가 필요하므로 Android Studio로 한 번 열어서 `local.properties`가 만들어진 뒤에 하세요.

## 2. 폰에서 처음 설정

1. **접근성 서비스 켜기**: 앱의 [접근성 서비스 켜기] → 설치된 앱(설치된 서비스) → **이미지 매크로** → 사용.
   - 회색으로 막혀서 안 켜지면 APK로 직접 설치했을 때 생기는 Android 13+ 제한입니다. **설정 → 앱 → 이미지 매크로 → 오른쪽 위 ⋮ → '제한된 설정 허용'**을 누른 뒤 다시 켜세요.
2. **알림 권한 허용** (Android 13+, 선택). 캡처 중 알림에 [캡처 중지] 버튼이 나옵니다.
3. **[화면 캡처 시작]** → 권한 창에서 **시작**을 누릅니다. Android 14+에서는 자동으로 '전체 화면'으로 설정됩니다.
4. 게임으로 이동하면 화면 위에 **조작 버튼**이 뜹니다: `✥ ▶시작 📷등록 ⚙`
   - ✥ 를 끌어서 게임 버튼을 가리지 않는 구석으로 옮겨 두세요. 조작 버튼도 캡처 화면에 찍혀요.

## 3. 이미지 등록 (윈도우판 templates / button 폴더 대신)

게임에서 해당 화면이 나왔을 때 **📷 등록**을 누릅니다.

1. 현재 화면이 열리면 **한 손가락으로 끌어서** 영역을 선택합니다. **두 손가락**으로 확대·이동할 수 있고, 확대하면 픽셀 단위로 보여요.
2. 위쪽 목록에서 종류를 고릅니다.
   - **회피 옵션 (새로 추가)**: 이름을 입력합니다 (예: 빙결).
   - **전투 시작 / 새로고침 / 확인 1 / 확인 2** 버튼
3. **저장**을 누릅니다. 한 화면에서 여러 개를 연달아 저장할 수 있고, 다 끝나면 **닫기**를 누르면 게임으로 돌아갑니다.

필요한 것: **버튼 4개 + 회피 옵션 1개 이상**. 앱 화면 '3. 이미지 등록'에서 등록 상태 확인과 삭제를 할 수 있어요.

> 💡 **글자 옵션은 다른 옵션과 겹치지 않는 부분만 자르세요.**
> 예: `빙결 시간` → `빙결`, `감속 효과` → `감속`.
> 윈도우판 스크린샷으로 시험해 보니 '빙결 시간' 전체를 쓰면 '기절 시간'과 0.876으로 비슷하다고 나왔지만,
> '빙결'만 쓰면 0.79로 떨어져 오인식이 사라졌습니다. 공통 글자('시간', '효과')가 점수를 올리는 원인이었어요.

> ⚠️ 윈도우(BlueStacks)에서 쓰던 PNG는 화면 해상도가 달라서 그대로는 잘 안 맞습니다. 폰에서 새로 캡처해서 등록하세요.

## 4. 실행

게임 화면에서 **▶ 시작**을 누르고, 멈출 때는 **■ 정지**를 누릅니다.
진행 상황은 조작 버튼 아래 한두 줄로 보이고, 전체 로그는 ⚙ → 앱 화면 아래쪽에서 볼 수 있어요.

## 5. 설정 (앱 화면 '4. 설정')

| 항목 | 기본값 | 설명 |
|---|---|---|
| 옵션 인식 임계값 | 0.92 | 높을수록 엄격합니다. 엉뚱한 옵션에 새로고침하면 올리고, 있는데 못 찾으면 내리세요 |
| 버튼 인식 임계값 | 0.85 | 윈도우판 기본값 |
| 전투 시작 후 대기 | 40초 | 윈도우판 START_WAIT_SECONDS |
| 검색 간격 | 300ms | |
| 클릭 후 대기 | 500ms | 새로고침이 두 번씩 눌리면 늘리세요 |
| 확인 버튼 최대 대기 | 120초 | 0 = 무한 대기 (윈도우판 동작) |
| 검색 배율 | 0.95,1.0,1.05 | 윈도우판과 동일 |
| 처리 해상도 비율 | 1.0 | 0.5로 하면 훨씬 빠르지만 작은 글자 인식이 약해집니다 |

## 문제 해결

| 증상 | 해결 |
|---|---|
| Sync할 때 `Unsupported class file major version` / JDK 오류 | Settings → Build → Gradle → **Gradle JDK**를 17 또는 21로 바꿉니다 |
| `org.opencv:opencv:4.10.0` 을 못 찾음 | `app/build.gradle`의 버전을 Maven Central에 있는 다른 버전(예: 4.9.0, 4.11.0)으로 바꿉니다 |
| 접근성 서비스가 회색이라 안 켜짐 | 위 2-1의 '제한된 설정 허용' |
| 캡처한 화면이 검은색 | 게임이 화면 캡처를 막는 경우(FLAG_SECURE)라서 이 방식은 쓸 수 없습니다 |
| 화면을 끄면 매크로가 멈춤 | Android 14+는 화면이 잠기면 캡처가 자동 종료됩니다. 화면 켜짐 유지(개발자 옵션 '충전 중 화면 켜짐' 등)를 쓰세요 |
| 버튼을 찾는데 클릭이 안 먹음 | 조작 버튼이 그 위치를 가리고 있지 않은지 확인합니다. 접근성 서비스를 껐다 켜 봅니다 |
| 회전 후 인식이 안 됨 | 캡처 크기가 자동으로 다시 맞춰집니다. 계속 안 되면 캡처를 중지했다가 다시 시작하세요 |

## 코드 구조

```
app/src/main/java/com/imagemacro/
  MacroEngine.java              윈도우판 run_macro_loop 를 그대로 옮긴 본체 (안드로이드 의존성 없음, PC에서 테스트함)
  OpenCvVision.java             윈도우판 multi_scale_match (OpenCV)
  ScreenCaptureService.java     화면 캡처 (MediaProjection, 회전 대응)
  MacroAccessibilityService.java  자동 터치 + 게임 위 조작 버튼
  MacroController.java          엔진 시작/정지, 로그, 📷 등록 캡처
  MainActivity.java             앱 화면 (권한/등록 이미지/설정/로그)
  CropActivity.java, CropView.java  이미지 자르기·등록
  ImageStore.java, MacroSettings.java  저장소/설정
```

- 요구 사항: Android 8.0 (API 26) 이상
- 빌드: Android Gradle Plugin 8.7.3, Gradle 8.14.3, compileSdk 35, Java 17

> 게임 이용약관에서 매크로를 금지하는 경우 계정 제재를 받을 수 있으니 유의하세요.
